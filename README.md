# SAFOLLO STUDY CENTER — HSC ICT Interactive Book 2027
## Chapter 03: সংখ্যা পদ্ধতি ও ডিজিটাল ডিভাইস

শিক্ষক: **Unus Ali Sir | Lecturer-ICT**

### ফাইল
- `index.html` — ওয়েব অ্যাপের কাঠামো ও কনটেন্ট
- `style.css` — ডিজাইন, রেসপনসিভ লেআউট ও ডার্ক মোড
- `app.js` — ক্যালকুলেটর, বাইনারি সিমুলেটর, লজিক গেট, MCQ ও ইন্টারঅ্যাকশন

### GitHub-এ আপলোড
1. `https://github.com/shikkharkotha/ICT-BOOK` খুলুন।
2. **Add file → Upload files** নির্বাচন করুন।
3. ZIP ফাইলটি আগে Extract করুন।
4. Extract করা ফোল্ডারের ভেতরের `index.html`, `style.css`, `app.js`, `README.md` এবং `assets` ফোল্ডার আপলোড করুন।
5. নিচে **Commit changes** চাপুন।
6. Settings → Pages → Deploy from a branch → `main` → `/ (root)` নির্বাচন করে Save দিন।
7. প্রকাশিত ঠিকানা: `https://shikkharkotha.github.io/ICT-BOOK/`

### স্থানীয়ভাবে পরীক্ষা
`index.html` ফাইল ব্রাউজারে খুললেই চলবে। ইন্টারনেট ছাড়া মূল ফিচারগুলো কাজ করবে; Google Fonts লোড করতে ইন্টারনেট লাগতে পারে।

### ভিডিও ও PDF যুক্ত করা
`index.html`-এর `#resources` অংশে `href="#"` পরিবর্তন করে নিজের YouTube বা PDF URL দিন। PDF চাইলে `assets/notes-chapter-03.pdf` নামে ফাইল রেখে লিংক দিন:
`href="assets/notes-chapter-03.pdf"`

### গুরুত্বপূর্ণ
- কুইজের স্কোর ও পড়ার অগ্রগতি একই ব্রাউজারের `localStorage`-এ থাকে; এটি অনলাইন সার্ভার বা শিক্ষক অ্যাডমিন প্যানেলে জমা হয় না।
- শিক্ষার্থীর লগইন, কেন্দ্রীয় ফলাফল, লাইভ ক্লাস বা সার্ভারভিত্তিক ডেটাবেস এই static version-এ নেই।
- পাঠ্যবিষয়গুলো শিক্ষণ-সহায়ক সংক্ষিপ্ত নোট; বোর্ডের সর্বশেষ পাঠ্যবইয়ের সঙ্গে মিলিয়ে পূর্ণাঙ্গ শিক্ষক-সম্পাদনা করুন।
